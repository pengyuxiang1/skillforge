# 案例库索引

skillforge 的生产案例库。**每完成一次值得沉淀的生产（Stage 5 判定），必须在此登记**，否则下次找不到。

> 格式模板见 [TEMPLATE.md](TEMPLATE.md)。

## 案例

| 案例 | 工作流 | 状态数 | 引导脚本 | 门禁 hook | 沉淀日期 |
|------|--------|--------|---------|----------|---------|
| *（暂无——你的第一个案例将出现在这里）* | | | | | |

## 快速检索

**按方法论找**：
- {...} → [{case}]({case}.md) {章节}

**按坑找**：
- {...} → [{case}]({case}.md) {章节}

**按可复用模板找**：
- {...} → `{文件路径}`

## 登记方法

1. 复制 [TEMPLATE.md](TEMPLATE.md) 为 `{skill-name}.md`，按节填写
2. 在上方表格加一行：`| [案例名](文件名.md) | 工作流一句话 | 状态数 | ✅/❌ 脚本名 | ✅/❌ hook名 | YYYY-MM-DD |`
3. 在「快速检索」节补上新增的方法论 / 坑 / 模板入口

## 什么值得登记（判定标准）

| 值得（有其一即可） | 不值得 |
|------------------|--------|
| 出现了新方法论 | 常规实现（照模板填空） |
| 踩到了新坑 | 已有案例覆盖过的场景 |
| 产出可复用的模板/脚本 | 一次性调试过程 |

**宁可少沉淀**——案例库的价值在于"精"，堆满常规案例就没人看了。
